# cartelera

Cineteca Nacional's showtimes (México, Chapultepec, Las Artes), scraped into
one static page: day agenda grouped by sede, posters, one-click tickets. No
backend, no build step. Updates twice a day via GitHub Actions.

Live at [cartelera.heliouz.com](https://cartelera.heliouz.com).

## Structure

```
scraper/        Python scraper (requests + BeautifulSoup)
docs/           static site (GitHub Pages root)
docs/data/      schedule.json, generated by the scraper
docs/og.png     link-preview image for every URL on the site
.github/workflows/scrape.yml   cron 2x/day + workflow_dispatch
```

## Scraper

```bash
cd scraper
pip install -r requirements.txt
python scrape.py
```

Writes `docs/data/schedule.json`. Aborts (exit 1, no write) if more than 20%
of detail-page fetches fail, or if the parsed film count drops below 50% of
the previous run — see `scrape.py` for the safeguards.

Each showtime carries `buy_url`, a direct link to that screening's checkout
page, read straight off the ticket anchor it was parsed from.

### Tests

```bash
cd scraper
pip install pytest
python -m pytest test_parse.py -v
```

Runs offline against fixtures in `scraper/fixtures/`. No network requests.

## Frontend

No build step. To test locally:

```bash
cd docs
python -m http.server 8000
```

All filtering (day, sede, ciclo, search) happens client-side against the
already-fetched JSON.

## Deploy

GitHub Pages, deployed from `main` / `/docs`. The scrape workflow commits
`schedule.json` only when it changes — that commit is the deploy, no build
step. It opens a `scrape-failure` issue if a run fails.

Custom domain `cartelera.heliouz.com` is set via `docs/CNAME` and GitHub
Pages settings; DNS is a CNAME record at the registrar pointing to
`heliouz.github.io`.

## Not official

Not operated by Cineteca Nacional. Ticket purchases happen on the official
system (`cinetecanacional.net`); this project only aggregates and presents
the public schedule.
